# Cycle City Thihariya Website

A free, responsive static website built with plain HTML, CSS and JavaScript.

## Files
- index.html — website structure/content
- style.css — design and responsive layout
- script.js — mobile menu, year and WhatsApp inquiry form

## IMPORTANT BEFORE PUBLISHING
Replace the placeholder phone/WhatsApp number:
+94 70 000 0000
and the number `94700000000` in index.html and script.js with the business's real WhatsApp number.

You can also replace the emoji product visuals with real product photos later.

## Publish for free
One easy option is GitHub Pages:
1. Create a free GitHub account.
2. Create a new public repository.
3. Upload index.html, style.css and script.js.
4. Open repository Settings → Pages.
5. Select the main branch and root folder, then save.
6. GitHub will give you a free website address ending in github.io.

For a custom .com domain, you normally need to purchase the domain separately.
